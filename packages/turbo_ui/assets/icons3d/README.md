# 3D icons

Transparent PNGs copied from the design kit (`design/Turbo-component-kit/3d-icons`). The names and style match Microsoft's Fluent Emoji 3D set, which is published under the MIT licence (copyright Microsoft Corporation); the kit does not say where the files came from, so confirm the source with the designer. If they are Fluent Emoji, keep this notice and the MIT licence text with the app's open-source licences.

Use them through `TurboArt` and `HeroIcon(art: ...)`; do not reference the files directly.
